# Mod Quirk:

- The way things load, you can't simply swap because the game needs to reload.
- The best solution was to force close the game after you make a selection.
- You pick which 'skin' you want to use and, when you exit the mod menu, the game will close and reopen the launcher.
- This is the best way to solve the problem. Could there be a better way? Probably. Will I keep searching? Absolutely not.
